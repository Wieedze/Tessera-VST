# Naming — Candidats pour le VST

> 18 candidats classés par feeling, avec rationale, problèmes potentiels (trademark, domaine, prononciation FR/EN), et un score subjectif sur 5.

---

## Top picks (à explorer en priorité)

### 1. **Caesura** ⭐⭐⭐⭐⭐
- **Sens** : terme musical pour une pause/interruption brève dans une partition. Étymologie latine "couper".
- **Pourquoi ça marche** : double sens parfait — pause musicale ET découpe. Sonne sophistiqué, beau visuellement, distinctif.
- **FR/EN** : prononçable des deux côtés (sé-zoo-ra / si-ZHURE-ah).
- **Domaines** : `caesura.audio`, `caesura.fx` à vérifier (probablement libres en `.audio` / `.fx`).
- **Risque trademark** : à checker côté plugins audio, mais peu probable.

### 2. **Tessera** ⭐⭐⭐⭐⭐
- **Sens** : tesselle, fragment qui compose une mosaïque. Vient du grec/latin.
- **Pourquoi ça marche** : évoque parfaitement la décomposition d'un signal en grains/morceaux. Image mentale forte = mosaïque sonore.
- **FR/EN** : prononçable, joli son.
- **Domaines** : `tessera.audio` à vérifier.
- **Risque trademark** : il y a un studio "Tessera Studios" mais pas plugin audio à ma connaissance.

### 3. **Lacuna** ⭐⭐⭐⭐
- **Sens** : lacune, vide manquant dans un texte ou une mémoire. Évoque l'effet de glitch/dropout.
- **Pourquoi ça marche** : très en phase avec le concept "trous dans le signal" du sequencer (steps off, gates).
- **FR/EN** : prononçable des deux côtés.
- **Domaines** : `lacuna.audio` probablement libre.
- **Risque** : peut paraître intello/froid pour un public producteur grand-public.

### 4. **Refract** ⭐⭐⭐⭐
- **Sens** : réfracter, dévier. Métaphore parfaite pour transformer un signal.
- **Pourquoi ça marche** : court, percutant, anglais international.
- **FR/EN** : très facile.
- **Domaines** : `refract.audio` peut-être pris, à vérifier.
- **Risque** : il existe déjà des produits "Refract" dans la tech (pas plugin audio à ma connaissance).

### 5. **Schism** ⭐⭐⭐⭐
- **Sens** : rupture, scission.
- **Pourquoi ça marche** : sonne dark, agressif (collage avec le dark psytrance), évoque la coupure/rupture d'un beat.
- **FR/EN** : "Schism" est anglais ; en FR ça donne "schisme" (peu utilisé). Privilégier prononciation EN.
- **Domaines** : à vérifier.
- **Risque** : c'est un mot Beck (album) + un produit Pink Floyd-related dans le passé. À checker.

## Solides outsiders

### 6. **Quanta** ⭐⭐⭐⭐
- **Sens** : pluriel de quantum, plus petite unité discrète.
- **Pourquoi** : alignement parfait avec le concept granulaire (un grain = un quantum sonore).
- **Risque** : très utilisé en physique quantique = peut paraître générique tech.

### 7. **Pulsar** ⭐⭐⭐⭐
- **Sens** : étoile à neutrons qui pulse rythmiquement.
- **Pourquoi** : évoque la rythmicité du sequencer + ambiance sci-fi/dark.
- **Risque** : utilisé par UAD, Pulsar Modular est une marque connue de plugins. **Conflit probable**.

### 8. **Eidolon** ⭐⭐⭐
- **Sens** : phantom, image spectrale (grec).
- **Pourquoi** : très évocateur, dark, distinctif. Colle à l'esthétique psytrance.
- **Risque** : prononciation difficile pour le grand public (eï-DOH-lon).

### 9. **Nebula** ⭐⭐⭐
- **Sens** : nuage stellaire de gaz et poussières.
- **Pourquoi** : métaphore parfaite pour le grain cloud (= literally a nebula of grains).
- **Risque** : "Nebula" est utilisé par Acustica Audio (gros plugin). **Conflit probable**.

### 10. **Threnody** ⭐⭐⭐
- **Sens** : chant funèbre, lamentation.
- **Pourquoi** : très original, évocateur, dark. Penderecki a une œuvre célèbre du même nom.
- **Risque** : trop niche/sombre pour un produit grand public ?

## Plus courts / punchy

### 11. **Rift** ⭐⭐⭐⭐
- **Sens** : faille, déchirure.
- **Pourquoi** : court, percutant, métaphorique pour un glitch.
- **Risque** : trop générique en tech (Oculus Rift).

### 12. **Skein** ⭐⭐⭐
- **Sens** : écheveau de fils emmêlés.
- **Pourquoi** : original, peu utilisé, métaphore pour les multiples voix granulaires entrelacées.
- **Risque** : prononciation FR difficile (« skin » en EN).

### 13. **Helix** ⭐⭐⭐
- **Sens** : hélice, structure spiralée.
- **Pourquoi** : évoque la modulation, le mouvement.
- **Risque** : Line 6 a le pédalier "Helix". Peut créer confusion.

### 14. **Crux** ⭐⭐⭐
- **Sens** : cœur, point central.
- **Pourquoi** : court, masculin, sonne fort.
- **Risque** : un peu vague, pas spécifiquement audio.

## Plus créatifs / originaux

### 15. **Echolalia** ⭐⭐⭐
- **Sens** : trouble psychique de répétition compulsive.
- **Pourquoi** : magnifique pour décrire le step sequencer qui répète/sample/glitch.
- **Risque** : trop long, prononciation difficile.

### 16. **Aporia** ⭐⭐⭐
- **Sens** : impasse logique, paradoxe philosophique.
- **Pourquoi** : intello, distinctif, beau son.
- **Risque** : peut sembler prétentieux. Il existe un jeu vidéo "Aporia".

### 17. **Vellum** ⭐⭐⭐
- **Sens** : parchemin fin, surface translucide.
- **Pourquoi** : évoque la texture, le voile sonore.
- **Risque** : trop soft/ambient, pas assez en phase avec le côté glitch agressif.

### 18. **Stochast** ⭐⭐⭐⭐
- **Sens** : raccourci de "stochastique" (probabiliste).
- **Pourquoi** : reflète directement la nature probabiliste du sequencer + slicer. Original.
- **Risque** : un peu nerd.

## Ma reco finale

Si je devais choisir **3 finalistes** à creuser sérieusement (vérification trademark + domaines + reaction tests sur tes proches musiciens) :

1. **Caesura** — le plus distinctif et le plus musical
2. **Tessera** — le plus en phase avec l'identité granulaire/mosaïque
3. **Refract** — le plus accessible commercialement

**Tests à faire avant de trancher** :

| Test | Comment |
|---|---|
| Trademark check | [USPTO](https://www.uspto.gov/trademarks/search) + [INPI](https://www.inpi.fr/recherche-marques) côté EU |
| Domaines | namecheap.com — viser `.audio`, `.fx`, `.com` (sinon `.app`) |
| Plugin database | [KVR Audio](https://www.kvraudio.com) recherche du nom |
| Discord/Reddit | rapide search pour voir si une producer guild en a parlé |
| Vibe test | fais-le entendre/lire à 5 producteurs, demande "ça évoque quoi ?" sans contexte |

Dis-moi laquelle de ces 3 tu préfères ou si tu veux que je creuse une autre direction (ex: noms français, noms inventés, noms en deux mots).
